# StudyCircle

**Learn together. Move forward together.**

StudyCircle is a collaborative academic workspace designed to help classmates organize their schoolwork, manage deadlines, and learn together in one dedicated space.

Instead of relying on scattered messages and files, students can create or join study groups, organize subjects, track academic activities, view upcoming deadlines, and share a common workspace with their classmates.

## Key Features

- **Personal Dashboard** — View upcoming deadlines, overdue activities, and joined study groups.
- **Study Groups** — Create dedicated academic workspaces and invite classmates.
- **Subject Organization** — Keep group subjects organized in one place.
- **Academic Activities** — Manage quizzes, assignments, exams, projects, presentations, and other school activities.
- **Calendar** — Keep track of important academic dates and deadlines.
- **Progress Tracking** — Monitor personal progress by marking activities as not started, in progress, or completed.
- **Role-Based Access** — Support group administrators and members with appropriate permissions.

## Technology Stack

- **Frontend:** HTML, CSS, and JavaScript
- **Backend and Database Services:** Supabase
- **Database:** PostgreSQL
- **Authentication:** Supabase Auth
- **Security:** Row Level Security (RLS)

## Project Goal

StudyCircle aims to make academic collaboration more organized, accessible, and manageable by providing students with a shared space to coordinate their schoolwork, stay on top of deadlines, and support one another's learning.

The initial release focuses on essential academic organization and group collaboration, with more advanced features reserved for future development.
